# Brain Hack · CHRONOS

10–11 сыныптарға арналған шағын білім беру WebXR квесті. Бір зертхана, үш алгоритмдік сынақ, аяқталған финал. Қазақша, орысша және ағылшынша. Компьютер мен Meta Quest бір ойын логикасын қолданады.

## Іске қосу

Node.js 22+:

```sh
npm start
```

`http://localhost:8080` ашыңыз. Қосымша пакеттер орнату қажет емес. Балама: `python -m http.server 8080`. ES-модульдер мен JSON жүктелетіндіктен `file://` жарамайды.

Windows-та `powershell -ExecutionPolicy Bypass -File .\start.ps1` іске қосуға болады. Скрипт PATH ішіндегі Node.js не осы компьютердегі Codex Node ортасын табады. Басқа порт: `-Port 8081`.

Компьютер: басып сүйреу — шолу, панельді басу — әрекет, 1–3 — станциялар, Q/E — бұрылу, Esc — мәзір. Шлемсіз үш тапсырманы толық өтуге болады.

## GitHub репозиторийіне жүктеу

Мақсатты репозиторий: [kazievbeking/vr_algoritm](https://github.com/kazievbeking/vr_algoritm).

Git орнатылған және GitHub рұқсаты бар компьютерде:

```sh
git init
git add .
git commit -m "Build Brain Hack educational WebXR quest"
git branch -M main
git remote add origin https://github.com/kazievbeking/vr_algoritm.git
git push -u origin main
```

Егер `origin` бұрыннан бар болса, оны қайта қоспаңыз. Қашықтағы репозиторийде өзгерістер пайда болса, оларды алдымен біріктіріңіз; force push қолданбаңыз. GitHub веб-интерфейсіндегі **Add file → Upload files** арқылы жоба файлдарын бумаларымен бірге жүктеуге де болады.

## GitHub Pages

Репозиторийде **Settings → Pages → Source → GitHub Actions** таңдаңыз. Содан кейін **Actions → Publish static quest → Run workflow** іске қосыңыз немесе `main` тармағына push жасаңыз. Workflow алдымен логика тесттерін орындайды, содан кейін статикалық файлдарды жариялайды.

Ойын мекенжайы: `https://kazievbeking.github.io/vr_algoritm/`. Бұл URL Pages workflow-ы сәтті аяқталғаннан кейін жұмыс істейді. Әрбір `main` өзгерісі тесттерден кейін автоматты түрде жарияланады.

Барлық ресурс жолы салыстырмалы. CDN, серверлік бөлік, SQL, ақылы API және құпия кілт қажет емес. A-Frame 1.7.0 мен Noto Sans жергілікті сақталған, лицензиялары активтермен бірге берілген.

## Meta Quest

Шлем браузерінде жарияланған HTTPS URL ашыңыз. «VR режимі» басып, рұқсат беріңіз. Контроллер сәулесімен таңдап, триггермен басыңыз. Телепорт — белгіленген сақиналар мен станция батырмалары; оң таяқша — 30° бұрылу; Y — мәзір. Отырып ойнау мен дыбыс баптаулары 3D мәзірде бар. Барлық ойын әрекеті immersive VR ішінде қолжетімді.

WebXR қолжетімсіз болса компьютер режимі қалады. Компьютер localhost-ы шлем localhost-ы емес; LAN HTTP адресін WebXR үшін дайын шешім деп қолданбаңыз.

## Шектеулер

Физикалық Meta Quest қолжетімсіз: контроллерлер, стерео мәтін анықтығы, жайлылық және құрылғы өнімділігі бөлек тексерілуі тиіс. 10–15 минут — жоспарлы уақыт, оқушылармен өлшенген нәтиже емес. Көмекші — дайын репликаларға негізделген ережелер жүйесі; сөйлеуді түсінбейді және еркін жауапқа баға қоймайды. Барыс тек осы браузердің localStorage ішінде сақталады. Дыбыс Web Audio арқылы пайдаланушы әрекетінен кейін іске қосылады, мәтін әрдайым қолжетімді.
