# Әзірлеу күнделігі

2026-10-18. Бастапқы репозиторий бос екені анықталды. Құрылым мен талаптар бекітілді.

Жоспар: 1) A-Frame сахнасы және басқару; 2) қазақша canvas панелі; 3) робот бағдарламасы; 4) логикалық есік және салмақты граф; 5) көмекші, тілдер, сақтау; 6) дыбыс пен финал; 7) нақты тексерулер.

Архитектура: дербес ES-модульдер, JSON деректері, барлық құрылғыға ортақ әрекет диспетчері. Ойын статикалық HTTP/HTTPS арқылы іске қосылады. A-Frame 1.7.0 жергілікті сақталады. Серверлік логика, API кілті және генеративті модель қолданылмайды.

Шектеу: физикалық Meta Quest қолжетімсіз. Құрылғыдағы жайлылық, контроллерлер және өнімділік жеке тексерілуі тиіс. 10–15 минут — жоспарланған сабақ ұзақтығы; оқушылармен өлшенген нәтиже емес.

1–2 кезең орындалды: жергілікті A-Frame, Noto Sans қарпі, canvas-текстуралы кеңістік панелі, тінтуір мен контроллер сәулелері, белгіленген телепорт және 30° бұрылу қосылды. Canvas текстурасы қайта қолданылады, жойылғанда ресурстары босатылады.

3–4 кезең орындалды: такт бойынша робот орындаушысы, шектелген цикл редакторы, сегіз сенсор жиынын тексеретін есік, энергиясы есептелетін алты түйінді граф жасалды.

5–6 кезең орындалды: үш тілдегі мәтіндер, JSON репликалары, үш деңгейлі көмек, станциядан кейін сақтау, жалғастыру және жаңа ойын растауы, қысқа синтезделген дыбыстар, портал анимациясы және қорытынды панелі қосылды.

7 кезең басталды: Node.js арқылы 7 автоматты тексеру өтті. Одан кейін браузердегі толық өту мен тоқтатуды тексеру жүргізіледі.

7 кезең аяқталды: 7/7 логика тесті және Edge браузеріндегі толық сценарий өтті. Үш станция, қате жауаптар, робот пен портал орындауын тоқтату, қос іске қосу, 9 және 7 энергия шешімдері, сақтау/жалғастыру, тілдер және ұялы бет тексерілді. Толық соңғы іске қосу GitHub Pages тәрізді ішкі бумада өтті. JavaScript қатесі мен сәтсіз HTTP жүктеуі тіркелмеді. Жалғастырудағы финал және ұялы бет орбитасының асуы түзетілді. Скриншоттар `docs/screenshots/` ішіне, нақты есеп `docs/browser-report.json` ішіне сақталды. Нәтижелер `testileu.md` құжатында ажыратылды.

Жоба файлдары мен GitHub Actions жариялау workflow-ы дайындалды. Қашықтағы GitHub репозиторийіне жүктеу орындалмады. Физикалық Meta Quest тексеруі әлі қажет.
