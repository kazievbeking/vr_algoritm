# Үш сынақ алгоритмі

## 1. Лазерлі дәліз

Команданы таңдау → бағдарламаға қосу → орындауды бастау → әрекетті тексеру → нәтижені көрсету.

5×5 өріс. S = (0,4), P = (4,0). Робот жоғары қарайды. Әр команда бір такт алады. Әуелі такт артады және лазер фазасы жаңарады, содан кейін команда орындалып, шекара, кедергі және лазер тексеріледі. Тақ тактта екі лазер де қосулы; жұп тактта өшірулі. Күту мен бұрылу да такт алады. Бастапқы фаза — 0, өшірулі. Фаза кадр жиілігіне тәуелсіз.

Қайталау соңғы 1–3 жай команданы жалпы 2–4 рет орындайды. Алғашқы орындалуы санға кіреді. Кірістірілген цикл жоқ. Ең көбі 16 блок, 64 кеңейтілген қадам. «Соңғысын жою» соңғы блокты жояды. Орындау кезінде командалар өзгертілмейді, ағымдағы блок ерекшеленеді.

Мұғалімге шешім: Алға → Қайталау (1,4) → Оңға → Күту → Алға → Қайталау (1,4). Барлығы 10 такт. Күтуді алып тастағанда робот 7-тактта лазерге соғылады. Тоқтату орындау буынының нөмірін өзгертеді; ескі асинхронды қадам жаңа күйге әсер етпейді.

## 2. Құпия есік

Тексеруді таңдау → операторды өзгерту → шартты құрастыру → сегіз мысалды тексеру → есікті ашу немесе қатені көрсету.

Қажетті ереже: `T ≤ 40 AND (L ≥ 50 OR резерв) AND NOT қауіпті қысым`. Қауіпсіз температура шегі — 40°C қоса, жарық шегі — 50 қоса. Панельдегі блоктар дайын құрылым ішінде ауысады: температураның үш нұсқасы, ішкі AND/OR, екі сыртқы байланысты бірдей ауыстыратын AND/OR, қысымды терістеу.

Тексеру тек ағымдағы мысалды емес, сегіз жиынды салыстырады. Жиындарға T=40, T=41, L=49, L=50, резерв және қауіпті қысым кіреді. Кестеде нақты және күтілетін нәтиже, түспен сәйкестік көрсетіледі. «Мысал» батырмасы ағымдағы сенсорды ауыстырады.

## 3. Уақыт порталы

Байланысты түйінді таңдау → қабырға құнын қосу → қалған энергияны көрсету → маршрутты орындау → порталға қуат беру.

Алты түйін, оң салмақты бағытталмаған қабырғалар. Тек көрші түйінге өтуге болады. «Соңғысын жою» соңғы ауысуды қайтарады. Шек — 9 энергия, редактор шегі — 16 түйін.

Дейкстра алгоритмі ең аз уақытша қашықтықты таңдап, көршілердің бағасын жаңартады. Оптимум жол атауымен салыстырылмайды; графтан есептеледі. Қазіргі графта S→A→B→P = 7, S→C→B→P = 9; екеуі де қабылданады. S→C→P небәрі екі ауысу болғанымен 11 энергия, сондықтан қабылданбайды. Тиімділік = ең аз құн / соңғы құн × 100%.
