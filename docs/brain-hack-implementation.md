# Brain Hack жобасын қалай жүзеге асырдым

Мен Brain Hack жобасын 10–11 сынып оқушыларының алгоритмдік ойлауын дамытуға арналған шағын VR-квест ретінде жасадым. Оқушы уақыт циклінде қалған зертхананы үш тапсырманы орындау арқылы қалпына келтіреді.

## Қолданған технологияларым

Жобаны A-Frame 1.7.0, WebXR, JavaScript, HTML және CSS арқылы жүзеге асырдым. Unity немесе Unreal Engine қолданған жоқпын. Ойын логикасын ES-модульдерге, тапсырмалар мен диалогтарды JSON файлдарына бөлдім. Серверлік бөлік пен ақылы API қоспадым.

## Виртуалды зертхана мен басқару

Зертхананы қарапайым 3D геометриядан құрастырдым: станциялар, робот, сырғымалы есік, голограмма және портал жасадым. Еден жолақтары, төбе жақтаулары және жұлдызды терезелер арқылы кеңістікті толықтырдым. Қайталанатын архитектураны InstancedMesh арқылы біріктірдім. Басқару панельдерін 3D сахнаға орналастырып, компьютердегі тінтуір мен VR контроллерлерін ортақ әрекет жүйесіне қостым. Телепорт пен қадамды бұрылуды қарастырдым.

## Үш тапсырманың логикасы

Бірінші тапсырмада роботқа командалар тізбегін және бір деңгейлі қайталауды қостым. Лазерлерді кадр жиілігіне тәуелсіз такттармен ауыстырдым. Екінші тапсырмада логикалық шарт құрастыруды және оны сегіз сенсор жиынында тексеруді жүзеге асырдым. Үшінші тапсырмада маршруттың энергия шығынын есептеп, ең аз құнды Дейкстра алгоритмі арқылы таптым.

## Тілдер мен көмекші

Интерфейсті қазақ, орыс және ағылшын тілдерінде дайындадым. Қазақ әріптері дұрыс көрінуі үшін жергілікті Noto Sans қарпін canvas-текстураға шығардым. Айна көмекшісін дайын репликалар мен ережелерге негіздедім: ол қате мен көмек сұрауына жауап береді. Генеративті модель қоспадым.

## Сақтау және жариялау

Тіл, баптаулар және аяқталған станциялар туралы деректерді localStorage ішінде сақтадым. Жалғастыруды, сынақты қайталауды және жаңа ойын алдында растауды қостым. Жобаны GitHub репозиторийіне жүктеп, GitHub Actions арқылы GitHub Pages сайтында жарияладым.

## Тексеру нәтижесі

Алгоритмдерге арналған жеті автоматты тексеруді және браузердегі толық өтуді жүргіздім. Қате жауаптарды, тоқтатуды, қайта іске қосуды, тілдерді және сақтауды тексердім. Физикалық Meta Quest қолжетімсіз болғандықтан, шлемдегі жайлылықты, мәтін анықтығын және контроллерлерді нақты құрылғыда тексерген жоқпын.
