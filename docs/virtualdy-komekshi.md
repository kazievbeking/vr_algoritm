# Виртуалды көмекші

Айна — голографиялық ғалым бейнесіндегі ережелер жүйесі. Генеративті ЖИ емес, еркін сөйлеуді талдамайды. Барлық реплика `data/dialogues.json` ішінде үш тілде дайындалған. Мәтін — толыққанды байланыс арнасы; сөйлеу синтезіне тәуелділік жоқ.

Оқиғалар: `start` — сынақ мақсаты; `firstError` — бірінші қатеге жалпы бағыт; `repeatError` — қайталанған қатеге нақтылау; `hints` — көмек сұрауының үш деңгейі; `success` — сәтті аяқтау. Тиімсіз, бірақ жарамды маршрутқа бөлек локализацияланған реплика беріледі.

Көмек деңгейлері: жалпы қағида → нақты бағыт → толық мысал. Алғашқы қате толық шешімді ашпайды. Әр станцияның көмек деңгейі бөлек. Жаңа ойын оларды нөлдейді.

«Көмек» келесі деңгейді ашады, «Қай жері қате?» соңғы нақты қатені түсіндіреді, «Тапсырманы түсіндір» мақсатты қайталайды. Көмек сұраулары қорытындыда саналады. Еркін ауызша түсіндірмеге баға қойылмайды.
