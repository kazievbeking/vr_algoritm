# Технологиялар және архитектура

A-Frame 1.7.0 — HTML нысандары мен three.js арқылы 3D сахна құрады. WebXR — браузердің иммерсивті режимі. JavaScript ES-модульдері — сыртқы құрастырусыз жүктелетін ойын логикасы. HTML/CSS — бастау беті. JSON — тапсырмалар, репликалар, аудармалар. localStorage — станциядан кейінгі нәтиже және баптаулар.

Модульдер: `main.js` әрекеттерді байланыстырады; `game-state.js` барысты басқарады; `tasks/` таза алгоритмдерді сақтайды; `panels.js` панель мазмұнын сызады; `world-ui.js` canvas-текстура мен сәулемен басылатын аймақтарды жасайды; `scene.js` геометрияны құрады; `assistant.js` ережелерді қолданады. VR және компьютер бір диспетчерді шақырады.

Барлық міндетті әрекеттер 3D панельде бар. Кәдімгі HTML тек бастау мен компьютердегі қысқа жолақ үшін пайдаланылады. Текстура жаңартылғанда жаңа GPU текстурасы жасалмайды; бір canvas пен CanvasTexture қайта қолданылады. Панель жойылғанда текстура, геометрия және материал босатылады.

A-Frame жергілікті көшірмесі мен MIT лицензиясы `assets/vendor/` ішінде. Noto Sans қарпі және OFL лицензиясы `assets/fonts/` ішінде. Контроллер моделі жүктелмейді: сәуле жеткілікті. Ойынды ашу үшін сыртқы CDN қажет емес.

Тек салыстырмалы ресурс жолдары қолданылады. API кілттері, дерекқор, серверлік есептеу немесе тілдік модель жоқ.

Таңдалған нұсқа құжаттары: [laser-controls](https://aframe.io/docs/1.7.0/components/laser-controls.html), [cursor](https://aframe.io/docs/1.7.0/components/cursor.html).
