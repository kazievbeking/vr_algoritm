# Пайдалану нұсқаулығы

1. Компьютерде Node.js 22+ орнатып, жоба бумасында `npm start` орындаңыз. `http://localhost:8080` ашыңыз. Немесе `python -m http.server 8080` қолданыңыз. Файлды екі рет басып `file://` арқылы ашпаңыз.
2. Тілді таңдаңыз. «Бастау» жаңа ойын ашады; бар барыс болса өшіруді растайды. «Жалғастыру» соңғы аяқталған станциядан кейінгі қауіпсіз күйді ашады.
3. Бірінші станцияда командаларды жинап, «Іске қосу» басыңыз. Лазер фазасын және келесі тактты бақылаңыз. Қате болса соңғы команданы жойыңыз, толық тазартыңыз немесе әрекетті қалпына келтіріңіз.
4. Екінші станцияда шарт блоктарын ауыстырып, барлық сегіз мысалды тексеріңіз. Қате жолдың күтілетін нәтижесін салыстырыңыз.
5. Үшінші станцияда тек байланысқан түйіндерді таңдаңыз. Жолды 9 энергиядан асырмай P-ге жеткізіңіз. «Іске қосу» роботты маршрутпен жүргізеді. Одан кейін «Порталға кіру» қорытындыны көрсетеді.
6. Көмек қажет болса үш көмек батырмасын қолданыңыз. Сынақты жеке қайталау жалпы ашылған станцияларды жаппайды. Жаңа ойын растаудан кейін ғана барысты алмастырады.

Meta Quest үшін GitHub Pages жарияланған HTTPS сілтемесін шлем браузерінде ашыңыз. «VR режимі» батырмасын өзіңіз басыңыз, браузер рұқсатын беріңіз. Бөлме шекараларын сақтап, қажет болса отырып ойнауды таңдаңыз.

Компьютердегі localhost шлемдегі localhost емес. Жергілікті желідегі жай HTTP адрес иммерсивті WebXR үшін жеткілікті қауіпсіз контекст емес. Негізгі тексеру тәсілі — жарияланған HTTPS сайт.

Сақтау істемесе ескерту шығады, ағымдағы бетте ойнау жалғасады. Зақымдалған сақтау қабылданбайды. Браузер деректерін тазалау барысты өшіреді.
