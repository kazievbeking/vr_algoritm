# Интерфейс, тілдер және жайлылық

Қазақ тілі — әдепкі. `locales/kk.json`, `ru.json`, `en.json` барлық панель, хабарлама және батырма аудармаларын сақтайды. JSON репликалары да үш тілде. Тіл localStorage ішінде сақталады. Мәзірдегі тіл батырмалары VR ішінде де қолжетімді.

Қазақша Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І таңбалары жергілікті Noto Sans қарпі арқылы canvas-қа салынады. Нәтиже бір canvas-текстура ретінде 3D панельге түседі, сондықтан стандартты A-Frame мәтін атласына тәуелді емес. Қаріп жүктелгеннен кейін панель жасалады.

Компьютер: тінтуірді басып сүйреу — қарау; панельді басу — әрекет; 1/2/3 — ашылған станцияға ауысу; Q/E — 30° бұрылу; Esc — мәзір. Еркін жүру орнына бекітілген нүктелер қолданылады.

Quest: екі контроллерде сәуле, триггермен басу; едендегі сақиналар не панельдегі станция батырмалары — бекітілген орынға телепорт; оң таяқша — 30° қадамды бұрылу; сол контроллердегі Y — мәзір. Отырып ойнау мәзірде ауысады. Бөлме ішіндегі шлем ығысуы телепортта ескеріледі, бұрылу ағымдағы бас орнының айналасында орындалады. Шлемнің нақты позасы күштеп жазылмайды.

Сахна өздігінен камераны жылжытпайды, шайқамайды. Резеңке көлеңке, ауыр постөңдеу, жыпылықтайтын әсер жоқ. HTML анимациясы жүйедегі reduced-motion баптауын ескереді. Негізгі 3D анимациялар — робот, есік, баяу портал және голограмма. Дыбыс мәзірде өшіріледі.

Физикалық шлемде мәтін өлшемі, отырғандағы биіктік және сәулемен батырманы дәл басу міндетті түрде тексеріледі.
