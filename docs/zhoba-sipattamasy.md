# Brain Hack оқу жобасы

Тақырып: виртуалды зертханадағы алгоритмдік ойлау. Аудитория: 10–11 сынып оқушылары. Мақсат: командалар ретін, қайталауды, логикалық шартты және салмақты графтағы тиімді маршрутты тәжірибе арқылы түсіндіру.

Өзектілігі: алгоритм нәтижесін тек код жолы ретінде емес, ортаның өзгерісі ретінде байқауға болады. Робот қозғалады, лазерлер фазасын өзгертеді, есік ашылады, портал қуат алады.

Сюжет: 2086 жылғы «Хронос» зертханасы уақыт циклінде қалды. Айна атты голографиялық көмекші үш жүйені қалпына келтіруге бағыт береді. Оқушы роботты өткізеді, қауіпсіз есік шартын құрады, энергияны порталға жеткізеді. Үш сынақтан кейін уақыт қалпына келеді.

Міндеттер: қауіпсіз әрі қайталанатын орындаушы; бірнеше мысалмен тексерілетін шарт; есептелетін маршрут құны; үш тілдегі түсінікті интерфейс; браузерде және WebXR ішінде ортақ басқару.

Сабаққа жоспарланған уақыт — 10–15 минут. Бұл ұзақтық оқушылармен тәжірибеде өлшенген жоқ. Педагогикалық тиімділік туралы зерттеу нәтижесі ұсынылмайды.
